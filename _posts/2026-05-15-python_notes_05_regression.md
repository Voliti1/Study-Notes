회귀분석(Regression Analysis)이란 하나 또는 그 이상의 **독립변수(원인)**가 **종속변수(결과)**에 미치는 영향력을 분석하고, 이를 바탕으로 미래의 값을 예측하는 대표적인 통계 분석 방법
---

## 1. 단순 선형회귀분석 (Simple Linear Regression)

### 1) 개념
하나의 독립변수(X)와 하나의 종속변수(Y) 간의 선형적 관계를 분석하는 기법으로 "원인이 단 하나일 때 결과가 어떻게 변하는가?"를 추적하는 분석 방법

### 2) 직관적 예시
- **공부 시간(X)**에 따른 **시험 점수(Y)** 예측
- **아파트 평수(X)**에 따른 **매매 가격(Y)** 예측

---

### 3) 파이썬 실습: 공부시간에 따른 시험 점수 예측

#### (1) 데이터 로드 및 확인
공부시간과 시험점수가 기록된 로컬 CSV 데이터를 로드하여 분포 파악

```python
import pandas as pd
study = pd.read_csv('./머신러닝실습용자료/공부시간과시험점수.csv', encoding='cp949')
study
```

**실행 결과:**
```
       이름  공부시간  시험점수
0     이원재  15.0  85.0
1     맹승주  14.5  86.5
2     안미경  14.0  86.0
...
23    이승우   7.5  73.5
24    일지매   7.0  73.0
```

- **이름**: 의미 없는 식별값
- **공부시간**: Feature (독립변수 $X$)
- **시험점수**: Target (종속변수 $Y$)

#### (2) 데이터 시각화 (산점도)
데이터의 경향성을 파악하기 위해 산점도 출력

```python
import matplotlib.pyplot as plt
data = study['공부시간']
target = study['시험점수']

plt.plot(data, target, 'o')
plt.show()
```

![공부시간과 시험점수 산점도]({{site.baseurl}}/assets/images/linear_regression_scatter.png)

공부시간이 증가할수록 시험점수도 우상향(선형 관계)하는 경향 확인

#### (3) 데이터 분할 및 차원 변형 (Reshape)
훈련 데이터와 테스트 데이터를 분리, 머신러닝 라이브러리 학습을 위해 1차원 배열 형태를 2차원 배열 형태로 변형

```python
import numpy as np
from sklearn.model_selection import train_test_split

# numpy 배열로 변경
data = study['공부시간'].to_numpy()
target = study['시험점수'].to_numpy()

# 훈련 세트와 테스트 세트 분리
훈련용_data, 테스트용_data, 훈련용_target, 테스트용_target = train_test_split(
    data, target, test_size=0.2, random_state=40
)

# 1차원 -> 2차원 변형
# scikit-learn의 입력값은 2차원 배열 형태여야 하므로 reshape(-1, 1)을 사용
훈련용_data = 훈련용_data.reshape(-1, 1)
테스트용_data = 테스트용_data.reshape(-1, 1)

print("훈련용 데이터 크기:", 훈련용_data.shape)
```

**실행 결과:**
```
훈련용 데이터 크기: (20, 1)
```

#### (4) 선형회귀 모델 학습 및 평가
`LinearRegression` 모델을 정의하고 학습시킨 후 결정계수를 평가

```python
from sklearn.linear_model import LinearRegression

# 모델 객체 생성 및 학습
lr = LinearRegression()
lr.fit(훈련용_data, 훈련용_target)

# 결정계수 확인
print("훈련 세트 R2 점수 :", lr.score(훈련용_data, 훈련용_target))
print("테스트 세트 R2 점수 :", lr.score(테스트용_data, 테스트용_target))
```

**실행 결과:**
```
훈련 세트 R2 점수 : 0.8869114576908868
테스트 세트 R2 점수 : 0.83676625848856
```

#### (5) 회귀계수 확인 및 예측
모델이 학습한 회귀계수(기울기 $\beta_1$)와 절편($\beta_0$)을 확인, 16시간 공부했을 때의 예상 시험점수를 예측

```python
# 회귀계수(기울기) 및 절편 확인
print("기울기(Slope):", lr.coef_, "절편(Intercept):", lr.intercept_)

# 16시간 공부 시 예측 점수
print("16시간 공부 예측 점수:", lr.predict([[16]]))
```

**실행 결과:**
```
기울기(Slope): [1.80042161] 절편(Intercept): 61.31748460585439
16시간 공부 예측 점수: [90.12423029]
```

- **최종 단순 회귀 방정식**: 
  $$Y = 61.3175 + 1.8004 \times X$$
  즉, 공부를 전혀 하지 않았을 때 기본 점수는 **61.32점**, 공부시간이 **1시간 증가할 때마다 시험 점수는 약 1.80점씩 향상**
- **예측**: 16시간 동안 공부하는 경우, 시험 점수는 **90.12점**으로 예측됨

#### (6) 회귀선 플로팅
```python
plt.scatter(훈련용_data, 훈련용_target, color='green', label='Train Data')
plt.scatter(테스트용_data, 테스트용_target, color='red', label='Test Data')
plt.plot([5, 18], [5 * lr.coef_[0] + lr.intercept_, 18 * lr.coef_[0] + lr.intercept_], color='blue')
plt.scatter(16, 90.12, marker='^', color='orange', s=150, label='Prediction (16h)')
plt.legend()
plt.show()
```

## 2. 다항 회귀분석 (Polynomial Regression)

현실 속 데이터는 항상 직선 형태로만 표현되지 않으며 곡선 형태를 띠기도 함. 독립변수의 단항식들을 다항식으로 매핑하여 곡선 형태의 회귀선을 그리는 기법이 **다항 회귀분석**

### 1) 파이썬 실습: 2차 곡선 모델 피팅
독립변수의 제곱 데이터를 피처에 추가하여 2차 함수 모델을 제작

```python
# 독립변수를 [X^2, X] 형태로 변경
훈련용_data_poly = np.column_stack((훈련용_data ** 2, 훈련용_data))
테스트용_data_poly = np.column_stack((테스트용_data ** 2, 테스트용_data))

# 다항 회귀모델로 재학습
lr_poly = LinearRegression()
lr_poly.fit(훈련용_data_poly, 훈련용_target)

# 성능 평가
print("다항회귀 훈련 세트 R2 점수 :", lr_poly.score(훈련용_data_poly, 훈련용_target))
print("다항회귀 테스트 세트 R2 점수 :", lr_poly.score(테스트용_data_poly, 테스트용_target))

# 16시간 공부 시 예측 점수
print("16시간 공부 예측 점수(다항):", lr_poly.predict([[16**2, 16]]))
```

**실행 결과:**
```
다항회귀 훈련 세트 R2 점수 : 0.9686934811074568
다항회귀 테스트 세트 R2 점수 : 0.5052713132458201
16시간 공부 예측 점수(다항): [85.24161226]
```

![다항 회귀선 피팅]({{site.baseurl}}/assets/images/polynomial_regression_fit.png)

### 2) 해석: 과대적합(Overfitting)의 교훈
- 다항식을 도입한 결과 훈련 세트의 결정계수($R^2$)는 **0.8869 $\rightarrow$ 0.9687**로 크게 증가하여 학습 데이터는 거의 완벽히 설명
- 그러나 테스트 세트의 결정계수는 **0.8368 $\rightarrow$ 0.5053**으로 심각하게 하락
- 이는 모델이 훈련 데이터의 사소한 노이즈까지 지나치게 맞추어 학습한 결과, 새로운 데이터에 대해 일반화 성능을 잃어버리는 **과대적합(Overfitting)**이 일어났음을 의미. 따라서 독립변수를 가공하여 차수를 과도하게 높일 때는 주의가 필요

## 3. 다중회귀분석 (Multiple Linear Regression)

### 1) 개념
현실 세계의 결과는 대개 한 가지 원인으로만 결정되지 않음. 다중회귀분석은 **두 개 이상의 독립변수들(X_1, X_2, ...)**이 하나의 종속변수(Y)에 미치는 영향을 동시에 분석하는 기법

### 2) 수학적 모델
$$Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \beta_3X_3 + ... + \beta_nX_n + \epsilon$$

- 각 독립변수($X_i$)는 고유의 회귀계수($\beta_i$)를 가짐
- **해석 주의:** $\beta_1$은 다른 모든 독립변수($X_2, X_3...$)의 조건이 고정(통제)된 상태에서, $X_1$이 1단위 변화할 때 $Y$에 미치는 순수한 영향력을 의미

### 3) 직관적 예시
- **공부 시간($X_1$)**, **학원수($X_2$)**, **과외여부($X_3$)**를 함께 고려한 **최종 시험 점수($Y$)** 예측
- **아파트 평수($X_1$)**, **역세권 여부($X_2$)**, **준공 연도($X_3$)**를 함께 고려한 **매매 가격($Y$)** 예측

---

### 4) 파이썬 실습: 여러 원인을 반영한 시험 점수 예측

#### (1) 데이터 로드 및 분할
이번에는 `공부시간`, `학원수`, `과외여부` 3가지의 독립변수가 포함된 데이터를 다룸.

```python
# 데이터 로드
study = pd.read_csv('./머신러닝실습용자료/공부시간과시험점수2.csv', encoding='cp949')

# 다중 독립변수 지정 (공부시간, 학원수, 과외여부)
data = study[['공부시간', '학원수', '과외여부']]
target = study['시험점수']

# 훈련/테스트 세트 분리
훈련용_data, 테스트용_data, 훈련용_target, 테스트용_target = train_test_split(
    data, target, test_size=0.2, random_state=40
)
```

#### (2) 모델 학습 및 성능 검증
```python
# 모델 생성 및 학습
lr_multi = LinearRegression()
lr_multi.fit(훈련용_data, 훈련용_target)

# 결정계수 R2 점수 확인
print("다중회귀 훈련 세트 R2 점수 :", lr_multi.score(훈련용_data, 훈련용_target))
print("다중회귀 테스트 세트 R2 점수 :", lr_multi.score(테스트용_data, 테스트용_target))
```

**실행 결과:**
```
다중회귀 훈련 세트 R2 점수 : 0.9326180323755402
다중회귀 테스트 세트 R2 점수 : 0.8967399286768529
```

- 단순 선형회귀에 비해 결정계수가 대폭 상승(테스트 세트 기준 약 **83.68% $\rightarrow$ 89.67%**),  여러 독립변수를 고려함으로써 모델의 예측 설명력이 더욱 높아짐

#### (3) 회귀계수 해석 및 예측
학습된 모델의 수식을 분석하고, **공부시간 13시간, 다니는 학원 5개, 과외 없음(0)**인 학생의 예상 점수를 확인해 봄.

```python
print("회귀 계수(Coefficients):", lr_multi.coef_)
print("Y 절편(Intercept):", lr_multi.intercept_)

# 예측 실행
print("공부시간 13시간, 학원 5개, 과외 X 학생의 예측 점수:", lr_multi.predict([[13, 5, 0]]))
```

**실행 결과:**
```
회귀 계수(Coefficients): [ 2.08625548 -0.22486821  0.31139414]
Y 절편(Intercept): 58.86959435570258
공부시간 13시간, 학원 5개, 과외 X 학생의 예측 점수: [84.86657458]
```

- **최종 다중 선형 회귀 방정식**:
  $$Y = 58.8696 + 2.0863 \times \text{공부시간} - 0.2249 \times \text{학원수} + 0.3114 \times \text{과외여부}$$
- **회귀계수의 순수 영향력 해석**:
  1. 다른 조건이 일정할 때, **공부시간이 1시간 늘어나면 점수는 약 2.09점 증가**
  2. 다른 조건이 일정할 때, **학원수가 1개 늘어나면 점수는 약 0.22점 감소**
  3. 다른 조건이 일정할 때, **과외를 받게 되면 점수가 약 0.31점 증가**
- **예측**: 수식에 따라 예측값을 계산하면 약 **84.87점**이 도출됨

## 4. 단순 선형회귀 vs 다중회귀 핵심 비교

| 구분 | 단순 선형회귀분석 | 다중회귀분석 |
| :--- | :--- | :--- |
| **독립변수 ($X$) 개수** | **딱 1개** | **2개 이상** (여러 개) |
| **종속변수 ($Y$) 개수** | **딱 1개** | **딱 1개** |
| **기하학적 형태** | 2차원 평면 위의 **직선 (Line)** | 3차원 이상의 공간 (3차원은 **평면/Plane**) |
| **장점** | 모델이 직관적이며 결과를 해석하기 쉬움 | 현실적인 데이터를 더 잘 반영하며 예측력이 높음 |
| **단점 및 한계** | 복잡한 현실의 인과관계를 설명하기에 부족함 | 독립변수가 늘어날수록 **다중공선성** 문제를 주의해야 함 |

## 5. 회귀분석 수행 시 필수 기본 가정 (Assumption)

회귀분석 모델이 신뢰성과 유효성을 얻으려면, 데이터와 모델의 오차항($\epsilon$)이 다음 4가지 조건을 충족해야 함

1. **선형성 (Linearity)**: 독립변수와 종속변수 간의 관계가 직선 형태(선형 관계)여야 함.
2. **독립성 (Independence)**: 오차항끼리 서로 상관관계가 없어야 함. 오차가 자기상관성을 띠면 모델의 신뢰도가 손상됨. (시계열 데이터에서 빈번히 중요하게 작용함)
3. **등분산성 (Homoscedasticity)**: 독립변수의 모든 범위에 걸쳐 오차항의 분산이 일정해야 함. 데이터의 값 크기에 따라 오차 폭이 커져서는 안 됨
4. **정규성 (Normality)**: 오차항의 분포가 평균이 0인 정규분포를 따라야 함. 정규성 가정이 어긋나면 회귀계수의 유의성 검정($t$-검정 등) 결과를 신뢰하기 어려움

---

## 6. 다중회귀분석의 핵심 주의점: 다중공선성 (Multicollinearity)

- **정의**: 독립변수들($X_1, X_2$)끼리 서로 너무 강하게 연관(높은 상관관계)되어 있어, 각 변수 고유의 개별 영향력(회귀계수 $\beta$)을 모델이 정확히 추정하지 못하고 결과가 불안정하게 왜곡되는 현상
- **구체적 예시**: 
  아파트 가격을 예측하는데 독립변수로 `평수($X_1$)`와 `방의 개수($X_2$)`를 함께 넣는 경우를 들 수 있음. 평수가 크면 당연히 방의 개수도 많으므로, 두 변수는 사실상 하나의 정보에 가까움. 이로 인해 모델이 두 변수 각각의 순수한 기여도를 분리하지 못하고 다중공선성 문제가 유발됨.
- **진단 방법**: 변수 간의 피어슨 상관계수를 체크하거나, **VIF(분산팽창지수, Variance Inflation Factor)**가 10 이상인 경우 다중공선성이 존재한다고 판단함.
- **해결책**:
  1. 상관관계가 높은 변수 중 중요도가 떨어지는 변수를 모델에서 제거
  2. 두 변수를 결합하여 새로운 파생변수(예: 면적당 방 개수 등)를 제작
  3. **PCA(주성분분석)** 등 차원 축소 기법을 활용하여 상관성이 없는 직교 주성분으로 변환
  4. L1/L2 규제(Ridge, Lasso, ElasticNet 등)가 추가된 정규화 모델을 도입하여 계수의 크기를 조절
