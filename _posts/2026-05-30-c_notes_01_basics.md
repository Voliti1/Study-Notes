## 1. C언어 개요 및 빌드 프로세스

C언어는 하드웨어 제어 및 고성능 애플리케이션 개발에 널리 사용되는 컴파일러 언어입니다.

### 1) 빌드 프로세스
* **전처리기(Preprocessor)**: `#include` 또는 `#define`과 같이 `#`으로 시작하는 지시어를 처리하여 소스코드에 삽입합니다.
* **컴파일(Compile)**: 소스코드(`.c`)를 기계어 파일인 목적 파일(`.obj`)로 번역합니다.
* **링크(Link)**: 여러 목적 파일과 라이브러리를 연결하여 실행 파일(`.exe`)을 생성합니다.

### 2) 컴파일러 vs 인터프리터
* **컴파일러**: 소스코드 전체를 한 번에 번역하여 실행 파일을 생성하므로 속도가 빠릅니다. (예: C, C++, Java)
* **인터프리터**: 코드를 한 줄씩 읽어가며 즉시 실행하므로 별도의 실행 파일이 필요 없고 유연하지만 속도가 다소 느립니다. (예: Python, JavaScript)

## 2. 변수와 기본 입출력

### 1) 식별자 조건
변수 및 함수의 이름(식별자)은 다음 규칙을 만족해야 합니다:
* 첫 글자는 영문자 또는 언더바(`_`)만 가능합니다. (숫자로 시작할 수 없습니다.)
* 공백이나 특수문자(언더바 제외)는 포함될 수 없습니다.
* 키워드/예약어(예: `if`, `for`, `while`, `case` 등)는 식별자로 사용할 수 없습니다.

### 2) 기본 입출력 함수
* **`printf()`**: 형식화된 데이터를 화면에 출력합니다.
* **`scanf()`**: 키보드로부터 데이터를 입력받아 주소 연산자(`&`)가 가리키는 메모리에 저장합니다.

```c
#define _CRT_SECURE_NO_WARNINGS // VS 환경에서 scanf 경고 제거
#include <stdio.h>

int main() {
    int age = 0; // 변수 초기화
    printf("나이를 입력하세요: ");
    scanf("%d", &age); // & 기호는 주소를 의미
    printf("입력된 나이는 %d세입니다.\n", age);
    return 0; // 정상적인 종료를 알림
}
```

## 3. 데이터 타입 및 연산자

C언어는 데이터의 종류와 메모리 크기를 컴파일 시점에 명시적으로 지정하는 **정적 타이핑(Static Typing)** 및 타입을 엄격히 유지하는 **강타입(Strongly Typed)** 언어의 특징을 보입니다. 단, C언어 내장 자료형에는 **String(문자열) 타입이 존재하지 않으며**, 문자형 배열 또는 포인터로 문자열을 표현합니다.

### 1) 기본 자료형
* **문자**: `char` (1byte, 작은따옴표 `'a'`로 표현)
* **정수**: `int` (4byte), `long` (8byte, 리터럴 뒤에 대문자 `L` 표기 권장)
* **실수**: `float` (4byte, 리터럴 뒤에 `f` 표기), `double` (8byte, 기본 실수 타입)
* **상수**: `const` 키워드를 변수 앞에 명시하며 선언 이후 값을 변경할 수 없습니다.

### 2) 주요 연산자
* **sizeof**: 데이터 타입 또는 표현식이 메모리에서 차지하는 바이트 크기를 반환합니다.
* **비트 시프트 연산자**:
  * `a << x`: 비트를 왼쪽으로 x칸 이동시키고 오른쪽은 0으로 채움.
  * `a >> x`: 비트를 오른쪽으로 x칸 이동시키고 왼쪽은 부호 비트(또는 0)로 채움.
* **삼항 연산자**: `조건식 ? 참일때_표현식 : 거짓일때_표현식`

## 4. 제어문 (조건문과 반복문)

### 1) 조건문
* **if / else if / else**: C언어에서는 파이썬의 `elif` 대신 `else if`를 명시적으로 작성합니다.
* **switch - case**: 특정 변수의 값에 따라 분기하며, 분기마다 `break;`를 걸어주지 않으면 아래의 case들이 연속해서 실행되는 Fall-through가 발생합니다.

### 2) 반복문
* **for**: `for(초기식; 조건식; 반복식)` 구조로 고정 횟수 반복에 유리합니다.
* **while**: 조건이 참인 동안 반복하며 조건 변경이 외부 요인에 의해 일어날 때 주로 사용합니다.
* **do-while**: 다른 반복문과 달리 **조건이 거짓이어도 최초 1회는 무조건 실행**된 후 조건을 검사합니다.

```c
#include <stdio.h>

int main() {
    int i = 0;
    
    // do-while 예시
    do {
        printf("최초 1회 무조건 실행 (i = %d)\n", i);
        i++;
    } while (i < 0); // 조건이 거짓이지만 1회 출력됨
    
    return 0;
}
```

## 5. 배열과 문자열

### 1) 배열의 정의와 특징
같은 자료형의 데이터를 일렬로 연속되게 모아놓은 집합입니다.
* **배열의 길이 계산**: `sizeof(배열명) / sizeof(배열명[0])`
* **메모리 특징**: 배열의 이름은 **배열의 시작 주소**와 같으며, 첫 번째 요소의 주소(`&array[0]`)와도 완전히 동일합니다.

### 2) 문자열 처리
C언어는 `char` 배열을 통해 문자열을 처리합니다. 문자열을 입력받을 때는 배열 이름 자체가 주소이므로 `scanf`에 `&`를 사용하지 않는 것이 원칙입니다.

```c
#include <stdio.h>

int main() {
    char name[10];
    printf("이름을 입력하세요: ");
    scanf("%s", name); // 배열명 자체가 주소이므로 & 기호를 붙이지 않음
    printf("반갑습니다, %s님!\n", name);
    return 0;
}
```
