## 1. 문자열 내장 메서드 및 StringBuilder

Java의 `String`은 불변 객체이므로 값 수정 시 새로운 객체가 할당됩니다. 따라서 잦은 문자열 변경 작업에는 가변 클래스인 `StringBuilder`가 권장됩니다.

### 1) 주요 내장 메서드
* **`equals()`**: 주소값을 비교하는 `==`와 달리, 문자열 자체의 내용물을 정밀 비교합니다.
* **`indexOf()`**: 특정 서브문자열이 등장하는 첫 번째 인덱스(위치)를 반환합니다.
* **`contains()`**: 문자열 포함 여부를 참/거짓으로 판단합니다.
* **`charAt()`**: 해당 인덱스 번호의 `char` 단일 문자를 추출합니다.
* **`replaceAll()`**: 정규표현식 매칭을 포함하여 문자열을 일괄 치환합니다.
* **`substring(start, end)`**: 시작 위치부터 종료 위치 직전까지의 부분 문자열을 슬라이싱합니다.
* **`split()`**: 구분자를 기준으로 쪼개어 문자열 배열(`String[]`)을 반환합니다.

### 2) StringBuilder의 사용
```java
StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.insert(0, "Good "); // 시작점에 삽입
sb.delete(5, 7);       // 인덱스 5부터 6까지 제거
String result = sb.toString(); // "Good Hllo" 형태로 변환
```

## 2. 핵심 컬렉션 프레임워크 (ArrayList, Map, Set)

Java 컬렉션은 객체 참조형 데이터만 다룰 수 있으므로, 제네릭(`<>`)에 반드시 **Wrapper 클래스**를 지정해야 합니다.

### 1) ArrayList
동적 배열 구조로 중간 삽입 및 삭제, 크기 성장이 동적으로 작동합니다.
* `add(value)`, `add(index, value)`: 요소 삽입
* `remove(index)`, `remove(Object)`: 요소 제거
* `sort(Comparator.naturalOrder())`: 오름차순 정렬

### 2) HashMap
키(Key)와 값(Value)의 쌍으로 데이터를 이루어 빠르게 검색하는 자료구조입니다.
* `put(key, value)`: 데이터 쌍 등록
* `get(key)`: 키에 매핑된 데이터 출력 (없는 경우 `null`)
* `containsKey(key)`: 특정 키의 존재 여부 확인

### 3) HashSet 및 이터레이터 (Iterator)
중복 저장을 허용하지 않고 순서가 없는 구조입니다.
* **집합 연산**:
  * `s1.retainAll(s2)`: 교집합 추출
  * `s1.addAll(s2)`: 합집합 병합
  * `s1.removeAll(s2)`: 차집합 제외
* **Iterator**: 컬렉션 내 요소를 안전하게 한 방향으로 순회하며 삭제할 수 있는 객체입니다. (`hasNext()`, `next()`, `remove()`)

## 3. Wrapper 클래스 및 형변환

Java는 기본 타입(Primitive Type)과 대응되는 참조용 Wrapper 클래스를 가지고 있습니다.
* **종류**: `int - Integer`, `char - Character`, `double - Double`, `boolean - Boolean` 등.
* **박싱(Boxing) & 언박싱(Unboxing)**: 기본값과 객체 간의 데이터 래핑 과정이며 JDK5부터 컴파일러가 알아서 해주는 **오토박싱/오토언박싱**을 지원합니다.
* **문자열 형변환**:
  * 문자열을 정수로: `Integer.parseInt("123")`
  * 숫자를 문자열로: `String.valueOf(123)` 또는 `Integer.toString(123)`

## 4. 기타 유틸리티 및 MySQL DB 연동

### 1) Switch Expression (JDK 14 이상)
화살표(`->`) 지시자를 도입하여 `break`문 선언 없이 간결하게 다중 비교 및 반환값 할당을 지원합니다.
```java
switch (grade) {
    case 10, 9 -> System.out.println("우수등급");
    case 8     -> System.out.println("보통등급");
    default    -> System.out.println("일반등급");
}
```

### 2) JDBC 라이브러리 연결
외부 MySQL DB와의 통신을 위해 다운로드한 Connector JAR 파일을 어셈블리 클래스패스에 추가하고 드라이버 접속 정보를 연동하는 전형적인 구조입니다.
```java
String url = "jdbc:mysql://localhost:3306/library";
String user = "root";
String password = "password";
// Connection conn = DriverManager.getConnection(url, user, password);
```
