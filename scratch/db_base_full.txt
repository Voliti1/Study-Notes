데이터베이스 - 특정 조직의 여러 사용자가 공유하여 사용할 수 있도록 통합해서 저장한 운영 데이터의 집합
ISOS : Integrated Data(통합 데이터), Stored Data(저장 데이터), Operational Data(운영 데이터), Shared Data(공유 데이터)
데이터베이스 시스템 특징 - R1C3 : Real time Accessibility(실시간 접근성), Continuous Evolution(계속적인 변화), Concurrent Sharing(동시 공유), Content Reference(내용 참조)
데이터베이스의 Pros & Cons
장점 - Data 중복 최소화, 중복 최소화로 저장공간 절약, Data Share 가능, 일관성, 무결성, 보안성 유지, 최신 데이터 유지, 데이터 표준화 가능, 데이터의 논리적, 물리적 독립성 확보, 
쉬운 데이터 접근
단점 - DB 전문 인력 필요, 시스템 운영비용 부담, 데이터 백업 및 복구 어려움, 시스템의 복잡함, 대용량 디스크로 액세스가 집중되면서 과부하가 발생
DBA - Database Administrator
DB 종류
계층형 : 트리구조, 데이터 중복 발생하기 쉽고 구조 변경이 어려움
네트워크형 : 그래프 구조, Data 중복, 구조 변경, 운영 어렵고 데이터 종속성 문제
키값 : NoSQL 한 종류, 키값 1v1 대응해 데이터 저장, 데이터 중복 발생, 비정형 데이터 유리, 해시테이블 구조, key value store 라고도 함
관계형, 객체형 DB
RDBMS
ERD(Entity Relationship Diagram)
International Standard - ANSI SQL(American National Standards Institute)
DDL : 스키마 정의, 수정, 삭제 - CREATE 테이블 생성, ALTER 테이블 수정, DROP 테이블 삭제, TRUNCATE 테이블 초기화
DML : 데이터 삽입, 삭제, 수정, 검색 - SELECT 데이터 조회, INSERT 데이터 입력, UPDATE 데이터 수정, DELETE 데이터 삭제
DCL : 내부적으로 필요한 규칙, 기법 정의(무결성, 보안, 회복, 동시성 제어)
 - GRANT 권한 부여 REVOKE 권한 삭제 COMMIT 트랜잭션 작업 완료 ROLLBACK 작업 취소 및 이전 상태로 복구

# SELECT 선택한 부분 FROM 테이블명 WHERE 조건(OR, AND, LIKE, BETWEEN)
SELECT title, author FROM books;
# AND, OR
SELECT * FROM books WHERE available=0 OR published_year > 2000;
SELECT * FROM books WHERE author = ‘생텍쥐페리’ AND published_year > 2000;
# BETWEEN : 숫자나 날짜 범위 지정
SELECT * FROM books WHERE published_year BETWEEN 1900 AND 2000;
# IN : 특정 값 집합에 포함
SELECT * FROM students WHERE major IN ("컴퓨터공학", "축구", "피겨스케이팅");
# LIKE : 부분 검색(% : 0개 이상의 문자(글자 수 제한 없음), _ : 정확히 1개의 문자)
SELECT * FROM books WHERE title LIKE "데%";
SELECT * FROM books WHERE title LIKE "데미안_";
SELECT * FROM books WHERE author NOT LIKE "김%";
SELECT * FROM students WHERE major LIKE "__";
# %가 포함된 전공이름검색, ESCAPE 문자 설정 !%, #% - 원래의 기능을 제거
SELECT * FROM students WHERE major LIKE "%#%%" ESCAPE "#";
# IS NULL, IS NOT NULL
SELECT * FROM students WHERE major IS NULL;
SELECT * FROM students WHERE major IS NOT NULL;
# ORDER BY : 정렬 (ASC 오름차순, DESC 내림차순)(오름차순이 defaut라서 생략 가능)
ORDER BY 정렬 기준

# LIMIT : 많은 데이터 중 일부만 확인, LIMIT 개수, LIMIT 시작숫자, 개수

# COUNT() : 행의 개수, SUM() : 합계, AVG() : 평균, MIN() : 최소값, MAX() : 최대값
SELECT count(*) AS total_books FROM books;
SELECT count(available) AS 대출가능권수 FROM books;
SELECT MIN(published_year) AS 가장오래된책 FROM books;
# GROUP BY : 그룹별 요약, HAVING : 그룹에 대한 조건
SELECT major, count(*) AS학생수, avg(age) AS 평균나이
FROM students
GROUP BY major
HAVING COUNT(*) >= 2;

# JOIN 주의사항
- ON 조건을 반드시 확인하기, 잘못 쓰면 데이터가 폭발적으로 늘어남 (곱집합 발생)
- 필요한 컬럼만 SELECT하기, JOIN할 때는 테이블 별칭(AS)를 사용해 가독성을 높이기
# INNER JOIN - 두 테이블에 모두 존재하는 데이터만 출력
SELECT s.name, b.title
FROM students AS s
INNER JOIN borrow AS br ON s.id = br.student_id
INNER JOIN books AS b ON br.book_id = b.id;
# LEFT JOIN - 왼쪽 테이블은 모두 출력하고, 오른쪽 테이블에 데이터가 없으면 NULL로 채움
# FROM에 있는 기준점이 되는 것이 왼쪽 테이블, JOIN 뒤에 위치한 것이 오른쪽 테이블
SELECT s.name, b.title
FROM students AS s
LEFT JOIN borrow AS br ON s.id = br.student_id
LEFT JOIN books AS b ON br.book_id = b.id;
# RIGHT JOIN - LEFT JOIN의 반대, 오른쪽 테이블을 기준으로 보여줌, LEFT JOIN을 더 자주 씀
# FULL OUTER JOIN(합집합) - 양쪽 테이블의 모든 데이터를 보여주는 JOIN - MYSQL에서 X
# CROSS JOIN(곱집합) - 모든 조합을 출력합니다. 
SELECT s.name, b.title
FROM students AS s
CROSS JOIN books AS b;

- 전공별 평균 나이를 구한 뒤, 그 결과에서 평균 나이가 25세 이상인 전공만 보기
#GROUP BY
SELECT major, AVG(age) FROM students
GROUP BY major HAVING AVG(age) >= 25;
#SubQuery
SELECT sub.major, sub.avg_age
FROM ( SELECT major, AVG(age) AS avg_age FROM students
    GROUP BY major ) AS sub
WHERE sub.avg_age >= 25;

# REGEXP : 정규 표현식(Regular Expression)
. : \n을 제외한 임의의 한 문자
* : 해당 문자 패턴이 0번 이상 반복
+ : 해당 문자 패턴이 1번 이상 반복
^ : 문자열의 처음을 의미
$ : 문자열의 끝을 의미
| : OR
[...] : 대괄호 안에 있는 어떠한 문자
[^...] : 대괄호 안에 없는 어떠한 문자
{n} : 반복되는 횟수 지정
{m, n} : 반복되는 횟수의 최솟값과 최댓값 지정
ex)
-- 'A'로 시작하는 이름을 찾기
SELECT * FROM users WHERE name REGEXP '^A';
-- 'son'으로 끝나는 이름을 찾기
SELECT * FROM users WHERE name REGEXP 'son$';
-- 'abc' 또는 'def'를 포함하는 레코드 찾기
SELECT * FROM products WHERE description REGEXP 'abc|def';
-- 우선순위 정렬: 숫자로 시작하는 제목을 먼저 보여주고 나머지를 정렬  
SELECT title FROM posts ORDER BY (title REGEXP '^[0-9]') DESC, title ASC;
